# Tiny18

Tiny18 is a split keyboard using the XIAO BLE.

---

ここからは日本語で失礼します。

Tiny18は神沼三平太の設計した左右分割各9キー、合計18キーからなる無線分割キーボードです。MCUにXIAO BLEを用いています。また、ダイレクトピン方式なので、ダイオードを利用していないことも特徴です。フットプリントはクレジットカードサイズ（54mm x 84.6mm）と小さく、持ち運びにも便利です。
